Privacy policy.

TubeMilestones is a local-first, open-source companion for YouTube creators. This page explains what the application accesses, where data goes, and how you can remove it.

Who operates TubeMilestones

TubeMilestones is an independent application maintained through the StealthMoud/TubeMilestones repository. It is not affiliated with or endorsed by YouTube or Google.

Google permissions requested

TubeMilestones requests only these read-only OAuth scopes:

  • youtube.readonly to read channel identity and public channel statistics.
  • yt-analytics.readonly to read authorized channel Analytics reports.

TubeMilestones cannot use these permissions to upload, edit, or delete videos, manage comments, or change your YouTube channel.

Data accessed and why

The application may access:

  • channel ID, title, thumbnail, creation date, and uploads playlist ID;
  • API-reported subscriber, view, and video counts;
  • daily views, watch minutes, subscriber gains and losses, and basic viewing-duration metrics;
  • the dates through which YouTube reports Analytics data.

This data is used only to show current position, milestone progress, locally observed achievement history, and simple Analytics summaries.

Where your data is stored

TubeMilestones has no application backend. Google and YouTube API data is requested directly by the code running in your browser. Channel history, milestones, custom goals, preferences, and manual values are stored in IndexedDB on that browser and device.

OAuth access tokens are kept only in live JavaScript memory. They are not written to IndexedDB, localStorage, cookies, the repository, or a TubeMilestones server. TubeMilestones does not request or store refresh tokens.

Manual data

If you enter qualified public watch hours, Shorts views, or custom goals, those values are stored locally in the same browser IndexedDB database. They are not sent to YouTube or a TubeMilestones service.

Retention, reauthorization, and deletion

Saved data remains on the browser and device until you clear it, disconnect, clear site data in your browser, or the browser removes storage. After 30 days without authorization verification, TubeMilestones requires you to reconnect before it displays saved channel data.

Disconnect attempts to revoke the active Google access token and deletes the selected channel data, snapshots, Analytics rows, milestone history, goals, and manual values from IndexedDB. Clear Local Data performs the same local deletion without representing that Google permission has been revoked.

You can also review or revoke access at Google Account permissions.

Google API Services User Data Policy

TubeMilestones' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security and device access

Local storage reduces data movement but does not make a device absolutely secure. Anyone with access to your unlocked browser profile may be able to inspect locally stored application data. Keep your device and browser profile protected.

Contact

For privacy questions or deletion concerns, open an issue in the TubeMilestones GitHub issue tracker. Do not include private channel data, access tokens, or account credentials in a public issue.

TubeMilestones is an independent application.
