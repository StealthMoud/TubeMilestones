Privacy policy.

This page explains which account and YouTube data TubeMilestones uses, why it is used, where it is stored, and how it is removed.

Operator and independence

TubeMilestones is an independent open-source application maintained through the StealthMoud/TubeMilestones repository. It is not affiliated with or endorsed by YouTube or Google.

Separate login and connected YouTube identities

TubeMilestones application login supports email/password or “Continue with Google” through Supabase Auth. Supabase Auth handles password hashing, email confirmation, and recovery; passwords are not stored in TubeMilestones application tables. Google login uses only basic profile, email, and OpenID information. Neither login method grants YouTube access.

“Connect YouTube account” uses a separate Google OAuth client. You may choose a different Google account from the one used to sign into TubeMilestones, and one TubeMilestones account may connect multiple Google/YouTube accounts. Each connection requests only these scopes:

  • openid and email to identify that connected Google account using its stable subject and, when verified by Google, show its email so you can distinguish it in Settings.
  • https://www.googleapis.com/auth/youtube.readonly for channel identity and statistics.
  • https://www.googleapis.com/auth/yt-analytics.readonly for the authorized channel's Analytics reports.

These permissions cannot upload, edit, or delete videos, manage comments, or change your channel. Google always presents an account chooser for a new connection or reconnect. Connected-account identity is derived by trusted server code, not accepted from browser input.

Data used

  • TubeMilestones login account ID, email, display name, and profile image;
  • for each connected YouTube authorization, Google's stable subject and a verified email label when available;
  • channel ID, title, thumbnail, creation date, uploads playlist, and API-reported subscriber, view, and video counts;
  • daily views, estimated watch minutes, subscriber gains/losses, average view duration, average view percentage, and reporting availability;
  • observed snapshots, milestone state, custom goals, theme, selected channel, and user-entered YouTube Partner Program guidance values;
  • authorization, synchronization, archive-manifest, and deletion lifecycle metadata needed to operate and secure the service.

Data is used to display current progress, honestly observed milestone history, simple Analytics, and the settings you request. It is not used for advertising or an AI/creator score.

Storage and processors

GitHub Pages serves only the application files. Supabase provides application authentication—including password hashes and email verification—sessions, database storage, row-level security, trusted functions, token Vault, and scheduled compliance/deletion work. Approximately 120 recent days are kept as hot database history.

Complete older months may be gzip-compressed and encrypted by TubeMilestones before being stored in a private Cloudflare R2 bucket. R2 is accessed only by trusted server functions; the browser does not receive R2 credentials or plaintext archive objects.

Google/YouTube supplies the authorized source data. GitHub supplies static hosting and source control but is not used as a user-data database.

Tokens and security

The YouTube authorization-code exchange and token refresh occur in Supabase Edge Functions. The Google client secret is server-only. A YouTube refresh token for each connection is stored through a separate Supabase Vault mapping and is not returned to the browser. Google provider-token fields from application sign-in are stripped before the Supabase session state is persisted by the app.

Database access is restricted by grants and row-level security. Archives use application-level AES-256-GCM encryption with per-user derived keys and integrity verification. No system can promise absolute security; protect your device and Google account and report suspected exposure without posting private data publicly.

Manual values and YouTube Partner Program

Optional qualified public watch hours, qualified Shorts views, and custom goals are stored in your TubeMilestones cloud account and are not sent to YouTube. These values are guidance only. TubeMilestones does not determine eligibility; YouTube Studio and current YouTube policies remain authoritative.

Retention, authorization, and deletion

Current state and encrypted history are retained while the account and its owning authorization remain active. Each authorization is periodically revalidated independently. Transient failures may be retried, but a permanent revocation or failure to verify by the 30-day limit starts the authorized-data purge lifecycle.

Disconnect targets one connected YouTube account: it requests best-effort Google revocation, removes that connection's stored Vault credential, deletes and verifies absence of encrypted R2 objects for its channels, then removes only its authorized database rows. Other connected YouTube accounts remain. It does not delete anything from YouTube. Signing out only ends the TubeMilestones session and does not revoke YouTube connections. Account deletion removes every connected YouTube account, the TubeMilestones profile, and the authentication account. Failures remain recorded for retry instead of being represented as complete.

You may also review or revoke access at Google Account permissions.

Logging and tracking

Operational logs may contain request correlation IDs, operation names, status, and safe error codes. They are designed not to contain OAuth codes, access or refresh tokens, secrets, archive plaintext, provider response bodies, or Analytics values. TubeMilestones does not include third-party advertising or product-tracking scripts.

Google API Services User Data Policy

TubeMilestones' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
